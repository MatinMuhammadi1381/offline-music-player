# 12 — Initial Agent Task

## Task: inspect and plan only

Read `00-AGENT-EXECUTION-PROTOCOL.md` and every document in this pack.

### Do now
1. Inspect the existing repository and report its current state.
2. Identify which decisions are already represented in code and which remain open.
3. Propose a phased plan based on `05-PHASE-ROADMAP.md`, adapting it to the actual repo.
4. Propose the minimum dependencies for Phase 1 and Phase 2, but do not install them.
5. Design the smallest useful iOS PWA file-access test and Android local-file/background-playback test.
6. Explain how each test will prove or disprove the relevant requirement.
7. Propose initial version metadata, changelog, Git tagging, and a Windows-friendly test runner if appropriate.
8. List any questions that block safe implementation.

### Do not do
- Do not create or modify app code yet.
- Do not install dependencies.
- Do not build detailed UI/UX.
- Do not copy any audio into browser storage.
- Do not publish any private music or metadata.
- Do not assume folder access works just because one-file selection works.
- Do not start Phase 1 until the owner approves the plan.

### Required response
Use the report template in `10-AGENT-REPORT-TEMPLATE.md`, adjusted for a plan-only response. End with the exact approval needed from the owner. Then stop.
